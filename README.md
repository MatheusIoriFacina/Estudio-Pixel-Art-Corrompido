# Pixel Art Corrompido

Projeto acadêmico de um jogo 2D de defesa desenvolvido na Godot.

## Carta

- Tema: Estúdio de pixel art com pixels corrompidos.
- Tipo: Defesa.
- Modo: Horda

## Objetivos

Controlar um artista e proteger um laptop por 3 minutos, 
enfrentando stickmans corrompidos usando ataques corpo a corpo.

## Regras

- O artista possui 3 pontos de vida.
- O laptop possui 5 pontos de vida.
- Cas o inimigo encoste no laptop, ele causa 1 ponto de dano.
- A partida dura 3 minutos.
- Caso a vida do artista e/ou do laptop cheguem a 0 a partida termina em derrota.
- A partida termina em vitória caso os 3 minutos acabem com o artista e o laptop vivos.

## Controles

W / Seta para cima - andar para cima.
A / Seta para esquerda - andar para esquerda.
S / Seta para baixo - andar para baixo.
D / Seta para direita - andar para direita.
