# Pixel Art Corrompido

Projeto acadêmico de um jogo 2D de defesa desenvolvido na Godot.

## Proposta

Um jogo de defesa em um estúdio de pixel art corrompido, na qual
um artista deve proteger um laptop que será atacado por inimigos
corrompidos.

O objetivo planejado é sobreviver por 3 minutos.
O laptop suporta 5 ataques de inimigos.
O combate será corpo a corpo.

## Recursos gráficos

Sprites produzidos para este projeto com auxílio de IA.
